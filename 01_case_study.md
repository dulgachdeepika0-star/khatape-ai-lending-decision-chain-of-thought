KhataPe Lending Decisions

Case Study

KhataPe is a fictional digital lender based in Indore. It provides small loans to kirana shop owners and college students.

Every month, KhataPe must choose between two loan products: Option A and Option B. The aim is to select the option that gives higher profit.

Decision Rules

1. Net Return = Interest Rate + Processing Fee − Expected Default − Cost of Funds.
2. Profit = (Net Return ÷ 100) × Loan Budget.
3. Choose the option with higher profit.
4. If both options have equal profit, choose the option with lower expected default.

Example

Option A:

* Interest rate = 22%
* Processing fee = 2%
* Expected default = 6%
* Cost of funds = 10%
* Net return = 8%
* Loan budget = ₹50 crore
* Profit = ₹4 crore

Option B:

* Interest rate = 18%
* Processing fee = 1%
* Expected default = 3%
* Cost of funds = 10%
* Net return = 6%
* Profit = ₹3 crore

Decision: Choose Option A because it gives higher profit.

Assumptions

Operating costs, taxes and timing of payments are ignored.
